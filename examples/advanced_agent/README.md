# Legacy AdvancedAgent Examples

This directory contains exploratory examples for the legacy `AdvancedAgent` and
`AgentConfig` APIs.

Keep these only as compatibility references. New examples should use
`ChatToolAgent` directly for small scripts, `AgentHarness` for managed loops,
and `NavigableMemory` for memory-enabled agents.

Some scripts in this folder expect local model servers, generated chat-history
files, or optional legacy memory dependencies.
